# AimMap (Android, Free + Pro)

Μία εφαρμογή: δωρεάν βασικές λειτουργίες + AimMap Pro με εφάπαξ αγορά μέσω Google Play (€1,49, id `aimmap_pro`).

## Δομή
- `www/index.html` η εφαρμογή (UI, λογική, Free/Pro). Δουλεύει και σε browser (χωρίς αγορές/διαφημίσεις).
- `src/native.js` γέφυρα προς Android: Google Play Billing, AdMob, κουμπί Back, αποθήκευση/κοινοποίηση αρχείων.
- `res-overlay/` εικονίδιο και splash από τα εικαστικά σου.
- `.github/workflows/build.yml` φτιάχνει debug APK και υπογεγραμμένο release AAB.
- `PLAY_STORE.md` τα βήματα σε Google Play Console, AdMob και GitHub secrets.

## Build (GitHub Actions)
1. Ανέβασε ΟΛΑ τα περιεχόμενα του φακέλου στη ρίζα ενός repository (μαζί με τον κρυφό `.github`).
2. Actions > "Build AimMap" > Run workflow (τρέχει και σε κάθε push).
3. Artifacts:
   - `AimMap-debug-apk`: για γρήγορο έλεγχο στο κινητό (διαφημίσεις δοκιμής, χωρίς πραγματικές αγορές).
   - `AimMap-release-aab`: για ανέβασμα στο Google Play (υπογράφεται αν έχεις βάλει τα secrets του keystore).

## Τι κάνει κάθε έκδοση
Free: κάμερα, χάρτης, πυξίδα, FOV, κώνος που φτάνει ως το άκρο του χάρτη με ενδείξεις απόστασης, ονόματα πόλεων/χωριών/κορυφών (χάρτης και κάμερα, από OpenStreetMap), ρυθμίσεις και μονάδες. Μία διαφήμιση πλήρους οθόνης μόνο όταν ανοίγει η εφαρμογή. Στην έξοδο (Back στην κύρια οθόνη) εμφανίζεται η οθόνη του Pro.
Pro: χωρίς διαφημίσεις, Saved locations, Direction lock, Geo screenshots, χρώμα/διαφάνεια κώνου, Export/Import (GPX, CSV).
Οι κλειδωμένες λειτουργίες έχουν εικονίδιο λουκέτου. Η αγορά ισχύει μετά από επανεκκίνηση ή επανεγκατάσταση με τον ίδιο λογαριασμό Google Play.

## Συμπεριφορά
- Άδειες (κάμερα, τοποθεσία): ζητούνται μία φορά στην πρώτη εκκίνηση. Μετά η εφαρμογή ανοίγει κατευθείαν.
- Back: κλείνει το ανοιχτό φύλλο, μετά Pro/Saved locations/Settings, επιστρέφει στην κύρια οθόνη, και από την κύρια οθόνη βγαίνει (στη Free δείχνει πρώτα το Pro).
- Η οθόνη δεν μένει ανοιχτή συνεχώς: ισχύει το timeout του κινητού.

## Νέα (v1.1)
- Οθόνη βαθμονόμησης πυξίδας: στην πρώτη εκκίνηση (πριν την κύρια οθόνη, χωρίς διαφήμιση), αυτόματα όταν οι ενδείξεις είναι κακές (πρώτα η βαθμονόμηση, μετά η διαφήμιση), και από Settings → Camera → Calibrate compass.
- Ο κώνος φτάνει πάντα ως το άκρο του χάρτη (σε κάθε zoom) και ξεθωριάζει με την απόσταση. Ενδείξεις απόστασης (1-2-5) κατά μήκος της κεντρικής γραμμής (Settings → Map → Show distance marks).
- Ονόματα τοποθεσιών (Free και Pro): πόλεις, κωμοπόλεις, χωριά, κορυφές. Στον χάρτη και πάνω στην κάμερα (με απόσταση/υψόμετρο). Γλώσσα από το σύστημα Android, αλλιώς αγγλικά. Δεδομένα από OpenStreetMap μέσω Overpass API (θέλουν internet, αποθηκεύονται προσωρινά στη συσκευή). Πάτημα σε όνομα στην κάμερα → «Align compass to this place».
- Η κάμερα ξαναξεκινά όταν η εφαρμογή επιστρέφει από το παρασκήνιο και αποδεσμεύεται όταν φεύγει.
- Δεν περιλαμβάνεται λήψη χαρτών για offline χρήση (ακυρώθηκε).
